## 项目介绍

周末经常会和朋友打掼蛋，但是老是打着打着就忘了这轮打几、谁贡牌了，所以写了一个网页端的掼蛋计分器，平时打牌的时候可以开着 iPad 放在旁边当实时的记牌器。

---

## 规则说明

项目以[《掼蛋基础规则基线》](docs/standard-rules.md)为准。核心升级规则为：头游方的对家是二游、三游、下游时，本方分别升 3、2、1 级；双方级数独立记录。项目用 A、A2、A3 表示第一、二、三次打 A，第三次仍未过 A 则退回 2。

---

## 使用方法

### 左侧：红方

- 点击本局结果即完成计分：+3（头/二）、+2（头/三）、+1（头/末）
- “撤销上一局”与结果按钮同宽同高，方便红方一侧就近操作

### 右侧：蓝方

- 点击本局结果即完成计分：+3（头/二）、+2（头/三）、+1（头/末）
- “撤销上一局”与结果按钮同宽同高，方便蓝方一侧就近操作

### 中间

- 当前打级方的大号级数（带颜色）
- 红蓝双方进度条
- 打 A 获胜时会显示皇冠动画

- 保留现有左右箭头灯状态，不额外显示“贡牌关系”文字区

---

## 适配

电脑和平板横屏使用红方 / 当前级数 / 蓝方三段式布局；手机与竖屏平板使用顶部当前级数、下方红蓝双列布局。所有计分和撤销按钮均支持触控与键盘操作。
